Intrusion Detection – live

Ein Modell bewertet Netzwerk-Flows als harmlos oder Angriff, ein zweites nennt den Angriffstyp, Claude schreibt eine Notiz für den Analysten – und ein Drift-Monitor merkt ohne Labels, wenn neue Angriffsarten auftauchen. Jeder Push auf main wird getestet, neu trainiert, gescannt und automatisch hier ausgerollt.
